## 1. ハードウェア概要と仕様

KeyKey は、リズムゲーム（osu! など）やクリエイティブ作業、ショートカット操作に最適な 2キー小型メカニカルキーボードです。

* **MCU コア**: WCH CH57x シリーズ 32-bit RISC-V マイコン
* **USB デバイス識別子**:
  * **本体キーボード**: Vendor ID `0x5262` (21090) / Product ID `0x4B4B` (19275)
  * **ワイヤレス電源モジュール**: Vendor ID `0x5262` (21090) / Product ID `0x504F` (20559)
  * **DFU ブートローダー**: Vendor ID `0x5262` (21090) / Product ID `0x0573` (1395)
* **通信規格**: 標準 USB HID クラス（Interface 3 出力・入力レポート通信）

## 2. 動作環境とインストール

### 動作環境
* **OS**: macOS 13.0 (Ventura)、macOS 14.0 (Sonoma)、macOS 15.0 (Sequoia) 以降
* **対応チップ**: Apple Silicon (M1/M2/M3/M4) および Intel プロセッサ両対応（Universal）
* **ドライバ**: 不要。Apple 純正 `IOKit.hid` フレームワークを使用するため、追加ドライバなしでプラグ＆プレイが可能です。

### インストール方法

#### 方法1：配布 DMG パッケージを使用（推奨）
1. GitHub の Releases ページより最新の `KeyKey-macOS.dmg` をダウンロードします。
2. DMG ファイルを開き、`KeyKey.app` を「アプリケーション」フォルダにドラッグ＆ドロップします。
3. `KeyKey.app` を起動します。

#### 方法2：ソースコードからビルド
```bash
git clone https://github.com/zpqnzpqn/KeyKey-Keyboard.git
cd KeyKey-Keyboard
open KeyKey.xcodeproj
```
Xcode でスキーム `KeyKey` を選択し、`Cmd + R` で実行します。

## 3. クイックスタート

1. 付属の USB Type-C ケーブルで KeyKey を Mac に接続します。
2. **KeyKey.app** を起動すると、ウィンドウ右上のインジケーターが「KeyKey 接続済み」（緑色）に変わります。
3. メイン画面の仮想キーパッドで「キー 1」または「キー 2」をクリックします。
4. キー割り当て、マクロ、または RGB ライティングを設定します。
5. **「デバイスに保存」** をクリックすると、キーボード本体の不揮発性メモリに直接書き込まれます。

## 4. 機能詳細

### 4.1 キーの割り当てと修飾キー
* **修飾キー**: `Ctrl`、`Shift`、`Option (Alt)`、`Command (Win)` を自由に組み合わせ可能。
* **標準キー**: F1～F12、数字、アルファベット、Backspace、Enter、Space、矢印キーを網羅。
* **メディアキー (16-bit Consumer)**: 音量調節、ミュート、再生/一時停止、トラック移動、画面輝度、電卓 (`0x0192`)、ブラウザホーム (`0x0223`)・戻る (`0x0224`)。
* **マウス操作**: 左右・中央・サイドボタンの組み合わせに加え、**X/Y カーソル移動量 (`-127〜127`)** と **ホイール回転量 (`-127〜127`)** を設定可能。

### 4.2 マクロ作成とリアルタイム録音
* **2種類のマクロ**: **キーボードマクロ（最大14ステップ）** と **マウスマクロ（最大8ステップ）** に対応。
* **時間設定**: 各ステップの押下時間および遅延時間を 10ms 単位（10ms〜2500ms）で精密調整可能。
* **ループ動作**: 「無限ループ」「長押し中ループ」「指定回数ループ（1〜250回）」を選択可能。
* **高リスクマクロ警告**: `Cmd+Space` や周期 20ms 以下の超高速無限ループを含む場合、書き込み前に安全確認ダイアログを表示します。

### 4.3 RGB ライティング設定とカスタム色
* **適用対象の切り替え**: **「両キー同期」**、**「キー 1 のみ」**、**「キー 2 のみ」** を選択可能。
* **トリガー / 常夜灯 / APM測定 / 消灯**: HSL スライダー（ハードウェアの `0〜255` スケールに自動変換）で自在に調整可能。

### 4.4 ワイヤレス電源モジュール (PowerOnMod)
* 電源オンを割り当てるキー（キー 1 または キー 2）を選択し、キーボードの Bluetooth MAC アドレスをモジュールに書き込んでペアリングします。片方のデバイスのみ接続時でも強制ペアリング解除が可能です。

### 4.5 キーストローク動作テスト機能
* アプリ内のテストフィールドで、設定したキーやマクロの入力を即座に確認できます。

### 4.6 プロファイル管理・USB/BLE 切替・ワンクリック安全初期化
* **ワンクリック安全初期化 (Factory Safe Reset)**: Write-Only フラッシュメモリを安全な単一キー（`Z` / `X`）で強制上書きし、未知のマクロを消去します。
* **プロファイル読込・自動同期 (`.json`)**: パラメータ境界チェックと安全性監査を行い、ハードウェアへ一括同期します。

## 5. ファームウェア更新 (DFU/IAP) と公式リンク

> [!CAUTION]
> ファームウェア更新中は、絶対に USB ケーブルを抜いたり、Mac の電源を切ったりしないでください。

* **公式サポート Wiki (Robit Wiki)**: [https://wiki.lbtrobit.com/zh/HID/KeyKeyBLE](https://wiki.lbtrobit.com/zh/HID/KeyKeyBLE)
* **公式 V1.0.2 誤操作防止・消灯版ファームウェア (`KeyKey_V102.bin`)**: [ZIP パッケージをダウンロード](https://pan.lbtrobit.com/f/aQQfR/KeyKey_V102_%E9%98%B2%E8%AF%AF%E8%A7%A6%E7%89%88.zip)

1. 「ファームウェア更新」タブで対象デバイス（キーボード本体または電源モジュール）を選択し、`.bin` ファイルを指定します。
2. 自動整合性チェック（サイズ `512B〜448KB`、RISC-V ベクタヘッダ、公式 SHA-256 ホワイトリスト）を確認後、「ファームウェア更新を開始」をクリックします。

## 6. よくある質問 (FAQ)

### Q1: キーボードが認識されません。
* 充電専用ケーブルではなく、データ通信対応の USB-C ケーブルをご使用ください。
* Mac 本体の別のポートに接続するか、右上の「再読み込み」ボタンを押してください。

### Q2: 別の PC (Windows) に接続しても設定は維持されますか？
* **維持されます。** 設定内容はキーボード本体のマイコンに保存されるため、別端末でもソフト不要で使用できます。

### Q3: 言語の変更方法は？
* 「環境設定」>「言語設定」より、**繁體中文 (台灣)**、**English**、**日本語**、**Español** を切り替えられます。
