## 1. 硬體介紹與規格

KeyKey 是一款專為高效生產力、快捷鍵操作與節奏遊戲（如 osu!）設計的雙鍵微型機械鍵盤。

* **MCU 核心**：沁恒微電子 (WCH) CH57x 系列 32 位元 RISC-V 核心單晶片。
* **USB 介面識別碼**：
  * **主鍵盤**：Vendor ID `0x5262` (21090) / Product ID `0x4B4B` (19275)
  * **無線開機模組 (PowerOnMod)**：Vendor ID `0x5262` (21090) / Product ID `0x504F` (20559)
  * **DFU 韌體升級模式**：Vendor ID `0x5262` (21090) / Product ID `0x0573` (1395)
* **通訊協定**：標準 USB HID 類別（使用 Interface 3 與專屬 Vendor 報告進行配置傳輸）。

## 2. 系統需求與安裝方式

### 系統需求
* **作業系統**：macOS 13.0 (Ventura)、macOS 14.0 (Sonoma)、macOS 15.0 (Sequoia) 或更高版本。
* **硬體架構**：原生支援 Apple Silicon (M1 / M2 / M3 / M4 系列) 與 Intel 處理器之 Mac 機型。
* **系統權限**：本程式採用 Apple 原生 `IOKit.hid` 架構，**無須安裝任何第三方驅動程式**即可直接讀寫配置。若使用「即時按鍵錄製」功能，macOS 將自動在應用程式前景攔截擊鍵事件。

### 安裝方式

#### 方式一：下載發行版直接安裝（推薦）
1. 前往 GitHub Releases 頁面下載最新版 `KeyKey-macOS.dmg` 或 `KeyKey.zip`。
2. 開啟 DMG 磁碟映像檔，將 `KeyKey.app` 拖曳至您的 `Applications` (應用程式) 資料夾。
3. 初次啟動時，若系統顯示安全性提示，請至「系統設定」>「隱私權與安全性」點擊「強制開啟」即可。

#### 方式二：使用 Xcode 從原始碼建構
```bash
git clone https://github.com/zpqnzpqn/KeyKey-Keyboard.git
cd KeyKey-Keyboard
open KeyKey.xcodeproj
```
於 Xcode 視窗頂部 Scheme 選擇 `KeyKey`，按下 `Cmd + R` 即可編譯並執行。

## 3. 快速上手指南

1. 使用 USB Type-C 傳輸線將 KeyKey 小鍵盤連接至 Mac 的 USB 連接埠。
2. 啟動 **KeyKey.app**，視窗右上角的連線狀態標籤將立即由灰色轉為綠色「KeyKey 已連線」。
3. 在主介面中央可見到擬真的雙鍵視覺化鍵盤（按鍵 1 與按鍵 2）。
4. 點選欲配置的按鍵（例如點擊按鍵 1），即可在下方切換按鍵類型、指派鍵碼、編寫巨集或調整燈光。
5. 完成後點選**「儲存到設備」**，設定將直接寫入鍵盤晶片的非揮發性記憶體，換電腦依然生效！

## 4. 功能詳解

### 4.1 按鍵自訂與圖層設定
在「按鍵自訂」分頁中，您可針對按鍵 1（硬體右鍵，`index 0`）與按鍵 2（硬體左鍵，`index 1`，可點擊視覺化鍵盤旁之 `⇄` 切換左右顯示順序）進行以下彈性設定：
* **修飾鍵組合**：可自由複選 `Ctrl`、`Shift`、`Option (Alt)`、`Command (Win)`。
* **標準鍵盤**：涵蓋完整的 F1～F12、數字鍵、QWERTY 字母鍵、Backspace、Enter、空白鍵、方向鍵與文書導航鍵。
* **多媒體控制（16-bit Consumer Controls）**：支援音量增減、靜音、音樂播放/暫停、上下曲切換、螢幕亮度調整、呼叫計算機 (`0x0192`)、瀏覽器首頁 (`0x0223`)、選單與返回 (`0x0224`)。
* **滑鼠動作（含游標位移與滾輪）**：支援複選滑鼠左鍵、右鍵、中鍵滾輪點擊、側鍵前進/後退，並可同時設定 **X 軸 / Y 軸游標位移 (`-127 ~ 127`)** 與 **滾輪捲動刻度 (`-127 ~ 127`)**。

### 4.2 巨集編程與即時錄製
巨集允許您將一連串繁複的操作簡化為單次擊鍵：
* **雙模步驟容量**：
  * **鍵盤巨集**：單鍵最多支援 **14 個動作步驟**（每步可選修飾鍵 + 標準按鍵 + 按下與延遲時間）。
  * **滑鼠巨集**：單鍵最多支援 **8 個動作步驟**（每步可設定滑鼠按鍵組合 + X/Y 位移 + 滾輪 + 按下與延遲時間）。
* **時間微調**：每個步驟皆可獨立設定「按下時間」與「延遲時間」（以 10 毫秒為步進單位，範圍 `10ms ~ 2500ms`）。
* **循環模式**：
  * **無限循環**：觸發後持續重複執行，直到再次按下停止。
  * **按住循環**：實體按鍵按住期間連續循環，鬆開立即終止。
  * **指定次數**：可精確指定重複次數（1～250 次）。
* **即時錄製**：點擊「即時錄製按鍵」後，直接在 Mac 鍵盤上依序敲擊按鍵，軟體會自動將 macOS 虛擬鍵碼轉換為 USB HID Usage ID 並加入清單！
* **高風險巨集安全提示**：若巨集包含 `Cmd+Space`、`Win+R` 或總週期 `<= 20ms` 之高速連續循環，系統會在寫入前主動彈出安全確認提示。

### 4.3 RGB 燈效調校與自訂色
KeyKey 內建兩顆獨立可尋址 RGB LED：
* **套用目標切換**：預設為 **「雙鍵同步 (套用至全部)」**（自動依序以 60ms 安全間隔寫入 LED 1 與 LED 2），亦可切換為 **「僅按鍵 1」** 或 **「僅按鍵 2」** 打造雙色撞色燈效。
* **按下亮燈 (觸發模式)**：支援幸運色 1、幸運色 2 與自訂指定色。
* **小夜燈模式**：支援指定色恆亮、指定色呼吸燈、彩虹動態流光。
* **手速測驗 (APM)**：鍵盤燈光將隨著您的打字或點擊頻率產生連鎖反應。
* **完全關閉燈光**：適合夜間睡眠或追求極簡的使用者。
* **色相/飽和度/明度 (HSL)**：提供直覺的色相 (`0°~359°`)、飽和度與明度滑桿（自動映射至硬體 `0~255` 階度）與即時預覽。

### 4.4 無線開機模組 (PowerOnMod) 配對
若您有選配電腦無線開機接收模組 (`PID: 0x504F`)：
1. 將 KeyKey 小鍵盤與無線開機模組同時透過 USB 連接至 Mac。
2. 在軟體中切換至「開機模組」分頁，選擇欲綁定為開機鍵的實體按鍵（**按鍵 1** 或 **按鍵 2**）。
3. 點擊「開始配對模組」，軟體將自動把鍵盤之 6-byte 藍牙 MAC 位址寫入開機模組並完成雙向綁定。
4. 若欲解除配對，點擊「解除配對」（支援單邊強制解綁，即使只插上其中一項設備亦可清除配對）。

### 4.5 鍵位即時測試區
軟體內建即時擊鍵測試輸入框與次數統計板：
* 配置完新按鍵後，無須開啟外部文字編輯器，直接在「按鍵測試」分頁測試。
* 系統即時顯示擊鍵日誌與累積點擊次數，適合進行開關觸發靈敏度測試。

### 4.6 設定檔備份、USB/藍牙切換與一鍵安全初始化
在「偏好設定」分頁中：
* **USB / Bluetooth 模式切換**：可一鍵切換鍵盤為有線 USB 模式或藍牙無線模式。
* **一鍵安全初始化 (Factory Safe Reset)**：由於硬體韌體為 Write-Only（不支援回讀內部巨集），若鍵盤曾連接未知電腦，點擊此按鈕可強制將雙鍵覆寫回安全的預設單鍵 (`Z` 與 `X`)、清除潛在隱藏巨集並恢復彩虹燈效。
* **匯出與匯入設定檔 (`.json`)**：匯入時自動執行參數邊界清洗與高風險巨集安全審查，並自動將雙鍵與燈效完整同步寫入硬體！

## 5. 韌體更新 (DFU/IAP) 與官方韌體取得

> [!CAUTION]
> 韌體更新會直接抹除晶片上的現有韌體並寫入新代碼。進行更新時，**請絕對不要拔除 USB 傳輸線或強制關閉軟體**！

### 官方韌體下載管道
* **原廠說明與韌體主頁（蘿蔔兔 Robit Wiki）**：[https://wiki.lbtrobit.com/zh/HID/KeyKeyBLE](https://wiki.lbtrobit.com/zh/HID/KeyKeyBLE)
* **官方 V1.0.2 防誤觸關燈版韌體 (`KeyKey_V102.bin`)**：[點此下載 ZIP 韌體包](https://pan.lbtrobit.com/f/aQQfR/KeyKey_V102_%E9%98%B2%E8%AF%AF%E8%A7%A6%E7%89%88.zip)
  * *版本說明：出廠預設韌體即為 `V1.0.2`。官方提供的「防誤觸關燈版 (`KeyKey_V102.bin`, 135,728 bytes)」移除了「同時按住雙鍵 3 秒切換燈效」的硬體快捷鍵，避免激烈按壓時誤觸亮燈（刷入後僅能透過軟體切換燈效）。*

### 更新步驟
1. 在「韌體升級」分頁中，先選擇升級目標設備（**KeyKey 鍵盤本體** 或 **無線開機模組**），再點擊「選擇韌體檔案...」選取 `.bin` 韌體。
2. 系統內建之「韌體安全檢查器」會自動驗證檔案長度（512B ～ 448KB，相容 WCH CH573F Flash）、檢查 RISC-V 向量表標頭（攔截 ELF/ZIP/空白檔）並比對官方 SHA-256 白名單。
3. 若為自訂未簽章韌體，需勾選「我了解風險，允許刷入未簽章或自訂開發者韌體」方可啟用更新。
4. 點擊「開始韌體更新」，軟體將透過原生 `IOKit.usb` Bulk 通道 (`0x5262:0x0573`, `EP_OUT=0x02, EP_IN=0x82`) 自動完成重啟進入 IAP、抹除、62-byte 分塊寫入、56-byte 分塊校驗與重啟。

## 6. 常見問題與疑難排解 (FAQ)

### Q1: 為什麼插入鍵盤後軟體顯示「未偵測到鍵盤」？
* 請確認傳輸線是否具備資料傳輸功能（部分充電線僅有供電功能，無資料線）。
* 請嘗試更換 Mac 的其他 USB 連接埠或轉接頭。
* 點擊視窗右上角之「重新整理」圖示手動觸發硬體枚舉。

### Q2: 更改設定後，更換到 Windows 或其他電腦會保留設定嗎？
* **會的！** 當您在軟體內點擊「儲存到設備」後，配置是直接寫入鍵盤硬體晶片的內部儲存空間，因此在免開軟體的情況下，拿到任何電腦或系統皆能直接使用該自訂鍵與巨集。

### Q3: 介面語言如何切換？
* 請至側邊欄「偏好設定」>「介面語言」中，自由切換 **繁體中文 (台灣)**、**English**、**日本語** 或 **Español**。
